# 測試與驗收

## 自動檢查

```sh
dart format --output=none --set-exit-if-changed lib test
flutter analyze --no-pub
flutter test --no-pub --reporter expanded
```

CI 的 `check` 通過後才建立 Android 與 Windows 產物。一般測試不連線 PTT，也不發送真實推文。

| 領域 | 測試內容 |
| --- | --- |
| 公開閱讀 | 分頁、刪文、置底、本文與推文分離、彩色文字保留、年齡 Cookie、主機與路徑限制 |
| 網址預覽 | 轉址、Open Graph、私人 IP／DNS／IPv6、循環轉址、圖片、快取與並行請求 |
| 終端 | 分段 Big5／UTF-8、Telnet 協商、ANSI 更新、中文字寬與滾動 |
| 狀態與介面 | 舊回應不覆蓋新看板、手機閱讀返回、桌面分欄與設定排版 |

## Windows 實機

- 解壓縮完整程式包，開啟 `ptt_client.exe`，確認一般與高 DPI 顯示。
- 搜尋看板、載入更早文章、閱讀與重新整理，確認已讀與位置保留。
- 放大視窗測試右側網頁預覽、圖片縮放與外部開啟。
- 測試中文輸入法、WebView2 Runtime 未安裝時的行為。

## Android 實機

- 安裝測試 APK，檢查直向、橫向、開啟鍵盤時的排版。
- 在 Wi-Fi 與行動網路切換，確認預覽設定。
- 網頁返回文章、程序被系統終止後的捲動位置與草稿。
- 關閉螢幕、背景、斷網後返回，確認連線狀態與重連入口，不重送發言。

## PTT 登入與發言

請以您擁有的帳號及允許測試的看板驗證，避免在無關看板張貼測試內容。

- 一般登入、錯誤密碼、重複登入、額外驗證與公告。
- 從不同位置切換文章，核對 AID、看板與標題。
- 推／噓／箭頭、字數、禁止噓文、權限與冷卻。
- 確認前與確認後各斷線一次；結果不明時提醒查證，不自動重送。
- 改變登入或推文提示後停止自動操作，終端仍可使用。

## 網址樣本

一般 HTTPS、HTTP、多次短網址、圖片直連、無 Open Graph、Big5 網頁、JavaScript 跳轉、驗證頁、登入頁、影片頁、失效網址、循環轉址與超大圖片。保留查詢參數及片段，不任意移除簽署或資源識別資訊。
