# 架構

本專案以 Flutter 共用 Windows 與 Android 的介面與業務邏輯，採裝置直接連線，無需自架後端。

| 模組 | 職責 |
| --- | --- |
| `PttWeb` | 經 HTTPS 讀取 PTT 公開看板、文章及推文，處理分頁與年齡確認 |
| `PttSession` | 經 WSS 直連 PTT、登入、辨識畫面、序列化看板／文章讀取與推文操作 |
| `PttBbsParser` | 解析終端列表、文章代碼、分頁行號與推文，產生共用閱讀資料 |
| `PttWireDecoder` | 登入前 Big5 分段解碼；帳號後加逗號協商 UTF-8，之後以串流解碼 |
| `TelnetDecoder` | 分段協定解析、終端型別及 80×24 視窗協商 |
| `TerminalScreen` | 有界 VT 螢幕，處理游標、清除、滾動區域、中文字寬與基本 ANSI 顏色 |
| `LinkPreviewService` | 短網址展開、Open Graph／HTML 標題、圖片、轉址檢查、快取與請求數限制 |
| `WebPreview` | Android WebView／Windows WebView2 的 App 內網頁瀏覽 |
| `AppModel` | 看板與文章載入狀態、讀取競態保護、釘選、閱讀紀錄與設定 |

## 讀取與登入

公開閱讀使用 `https://www.ptt.cc/bbs/...`，只允許指定主機與文章／索引路徑，不把 PTT 登入資訊附加到公開閱讀請求。

登入後，`AppModel` 改以 `PttSession.readBoard`／`readArticle` 讀取資料，不再依賴公開網頁。登入完成且連線解除操作鎖後，會自動重新載入目前看板，並使先前的 HTTP 回應失效。看板分頁使用本機 `ptt-bbs` 游標，不會將它送往網站；文章先依列表編號定位，再以 Q 解析完整 AID，取得穩定的文章網址。尚未解析的列表項目會核對作者、標題及選取位置，位置變動即停止並要求重載。

讀取沿用終端畫面以支援 PTT 的局部重繪，等待新的回應及短暫穩定後才解析。文章依頁尾行號合併重疊行，避免重複本文／推文；到達 100% 時停止翻頁，避免誤讀下一篇。超過 200 頁、未知提示、權限不足或連線中斷會回報錯誤，不以公開 HTTP 偷換讀取結果。讀取請求排隊執行，與登入及發言共用操作鎖。

登入使用 `wss://ws.ptt.cc/bbs`，握手來源為 `https://term.ptt.cc`。帳號後的逗號是 PTT 的 UTF-8 協商方式。登入前的 Big5 解碼僅處理傳統登入畫面；登入後交由 PTT 轉換 UAO 內容，客戶端接收 UTF-8。終端模式目前支援基本 ANSI，尚未完整實作雙色字與所有 VT 私有指令。

遇到重複登入、驗證器或其他額外提示，保留畫面交由使用者操作，不自行刪除其他連線。密碼只在記憶體內用於當次登入，不儲存或記錄。

## 推文

圖形化推文先回到主功能表、進入看板、以 AID 定位，再用 Q 查詢並核對站方回傳的完整 AID 與看板，最後核對標題。只有辨識到推文類型、內容及確認提示才送下一步。回顯不一致會取消，最後確認後逾時會回報結果不明，不自動重送。陌生畫面停止自動操作，保留內建終端供使用者處理。

未登入時公開文章的 HTML 可能有快取；登入後重新整理改由 PTT 連線讀取。正式發佈前仍需要使用測試帳號在允許測試的看板驗證登入與發言。

## 外部網址

預覽卡片由原生 HTTP 取得網頁資訊，不執行網頁 JavaScript。HTTP 轉址逐跳檢查，上限 6 次；循環轉址停止。HTML 上限 512 KiB、圖片上限 5 MiB，最多同時 3 個請求。結果快取 12 小時／128 筆，圖片快取 12 張，皆只在記憶體保存。

只允許一般 HTTP／HTTPS 與 80／443 連接埠。對主機名稱及 DNS 結果做基本私人網路檢查，圖片下載也使用同一流程。這些檢查不等同 DNS 釘選或完整的惡意網站防護。

完整網頁在使用者點擊後才建立 WebView。預覽頁不註冊讀取 PTT 帳密的 JavaScript 橋接，也不把登入資訊傳給外站。HTTP 網站可顯示，PTT 登入固定使用 WSS。JavaScript 轉址、驗證碼、登入及付費限制交由網頁本身處理；特殊登入可改用外部瀏覽器。

## 平台與資料

Windows 以分欄呈現閱讀，寬視窗可在右側顯示外站；Android 使用閱讀頁與內建瀏覽頁。釘選為此 App 本機清單，目前不與 PTT 伺服器上的「我的最愛」同步。登入後看板依帳號權限讀取；信箱與編輯功能可由終端操作。

SharedPreferences 保存帳號名稱、釘選、讀取紀錄、捲動位置、閱讀設定與推文草稿。這些資料沒有跨裝置同步；密碼不在其中。Android 背景期間可能失去連線，返回時以 Socket 的連線偵測更新狀態，保留閱讀與草稿，讓使用者重新登入。
